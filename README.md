# Sai Aashish — Developer Portfolio

A dark futuristic, responsive React + Vite portfolio. Includes project filters, project case-study modals, custom CSS preview illustrations, responsive mobile navigation and contact interaction.

## Run locally
Requires Node.js 20.19+ or 22.12+ recommended.

```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Personalize
Open `src/App.jsx`. The profile details are at the top. Sai Aashish and the Student Council President role are already filled in. Replace the email, GitHub and LinkedIn placeholders before publishing.

Project images can be added by setting each project's `image` property to an image path or URL. For local assets, place files in `public/images/` and use a path such as `/images/storygems-preview.png`.

Update project summaries, technology stacks, status labels, GitHub links and live-demo links so they accurately reflect the actual project. CSS preview art is illustrative, not a screenshot of a completed live project.

## Deploy
Push the project to GitHub, import it in Vercel, set build command to `npm run build` and output directory to `dist`.
